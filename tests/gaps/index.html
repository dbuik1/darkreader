Dark mode test pages

Each page reproduces one gap in Dark Reader. Open it with the extension on and compare against the expected result at the top of the page.

  • 2D canvas: light chart and a dark canvas
  • WebGL canvas: light scene that can't be sampled
  • Closed shadow DOM: closed and open components side by side
  • Images: screenshot, diagram, photo, icon
  • 200 images: scrolling performance
  • Text PDF: text, chart and a photo
  • Scanned PDF: one image per page, no text layer

Serve this folder over HTTP, for example python3 -m http.server 8000, then open http://localhost:8000. Opening files directly needs Allow access to file URLs on the extension.

To capture screenshots of each page with a built extension, run CHROME_PATH=<chrome binary> node tests/gaps/capture.js build/debug/chrome-mv3 <output folder> from the repository root.
